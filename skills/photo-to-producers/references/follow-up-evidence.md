# Follow-up evidence

Use for an incomplete reading, uncertain attribution, another view of an item,
or a correction. Keep the supported inventory useful while resolving the specific
gap; the user should not have to photograph everything again.

## Choose evidence that can change the result

Identify the reason an item remains unresolved before asking for another photo.

| Gap | Useful next step |
| --- | --- |
| Text is small, obscured or blurred | Reinspect a relevant region of the supplied image with the host's available tools. If it still cannot be read, request a close-up of that item and the missing label area, with a better angle or focus where relevant. |
| Brand is legible but the maker is uncertain | If a distinctive product name is readable, search it in Chisan's products before requiring a maker identity or another view. Verify candidate identities against the source. Look for an explicit maker statement on another supplied view or a narrowly relevant official source when needed; otherwise request that specific label area. Distinguish “made by”, “made for”, “distributed by” and “packed by”; an operator address or seller alone does not establish the maker. |
| A product or variant is legible but unresolved in Chisan | Check the selected producer's visible products and useful name alternatives. A catalog gap needs catalog/public product evidence. Ask for another view only if it can supply a missing distinction such as format or vintage; do not ask to rephotograph an already clear name merely because it was not found. |
| Catalog coverage, visibility or a tool is unavailable | State the unchecked scope and preserve earlier results. Another photo does not repair an unavailable search. Resume useful reads when available under the tool's continuation and retry rules. |

Prioritize the gaps that matter to the user's request. Name the item by its
visible position, explain which detail would distinguish the possibilities and
ask for the smallest useful view. State which details are already readable so
the user can focus on the missing label area.
Avoid asking for private receipts, personal details or unrelated images. A
readable front label plus a missing catalog entry can already support a research
lead; an additional photograph is not a universal prerequisite.

## Link another view to the right observation

Give a new image its own source reference. When the user or discriminating visual
evidence connects it to an earlier item, retain that link explicitly: a back-label
reading in `image-2` can support `image-1/item-4` without replacing its original
position or creating another shelf occurrence. Matching branding alone does not
prove that two images depict the same physical package or variant. Clarify an
uncertain correspondence only if it changes the attribution; meanwhile keep the
new view's readable evidence separately.

Use an explicit maker statement to reassess the relevant producer candidates.
Keep brand, maker and other printed roles distinct. A label-supported relationship
belongs to that observed item; it does not rewrite Chisan or establish who makes
every product sold under that brand. Matching the producer still does not match
the exact product, format or ingredient origin.

## Apply corrections to their dependent conclusions

Keep the original source readings separate from what the user corrects. If a
close-up was linked to the wrong item, remove that support from the old item and
reopen only the producer/product matches, grouping and research leads that relied
on it. Keep independently supported matches. A genuine separate item retains its
own source; withdrawing a mistaken link does not erase that source.

When a correction says two observations are different variants, split their
affected occurrences and leads. When evidence establishes a repeat, combine the
lead while retaining the sources. Do not restart unrelated catalog searches.

If the user asks only for changes, return the changed attribution, its source,
the supported Chisan link and the remaining blocker. Give the full revised
inventory when requested. Update any affected candidate's producer and next
question, and retain the distinction between prepared and actually saved work.
